---
name: Assistant-first navigation
description: Rationale for balancing a food-guidance-first mobile experience with discoverable legacy health records.
---

Keep the Food Guide as a primary destination, while retaining access to existing health-record sections through a secondary navigation area instead of removing them.

**Why:** The requested visual reference places guidance at the center of the experience, but the existing calendar, food notes, medications, and profile are real features with user data. Reducing tab clutter should not make those features disappear.

**How to apply:** When redesigning navigation or onboarding, prioritize the guidance and daily logging flow, but check that every established health-record route remains reachable and its underlying behavior intact.
